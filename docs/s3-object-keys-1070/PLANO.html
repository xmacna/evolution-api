🔎 Diagnóstico e correção

O backend usava path.join, cujo separador é nativo do sistema. No Windows, evolution-api + inst/audio/x.ogg produzia evolution-api\inst\audio\x.ogg. O problema já existia no PutObjectCommand, antes de qualquer chamada/assinatura AWS.

Hipótese Previsão e evidência
1. Composição nativa da chave path.join introduz barras invertidas; o probe nativo/POSIX confirmou os quatro casos.
2. Codificação do SDK Não explica as três falhas que já aparecem no comando falso antes da assinatura.
3. Entrada alterada pelo chamador Os testes fornecem a, y.bin e paths com /; o separador surge ao juntar os segmentos.

Troca mínima no backend: path.posix.join nos quatro pontos. Nenhum outro comportamento de storage foi alterado. O conjunto S3 existente já captura o bug nesta plataforma: baseline 3/7, com quatro diferenças de separador; candidato 7/7 dentro dos 82 testes da inbox. O arquivo S3 de testes conserva o mesmo hash LF entre baseline e candidato; não se enfraqueceram assertivas.
